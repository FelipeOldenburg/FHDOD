# 01: Questionário acessível por teclado e leitor de tela

**What to build:** permitir responder toda a pesquisa sem enxergar a tela ou usar mouse, preservando respostas, envio e regras do hospital.

**Blocked by:** None (can start immediately).

**Status:** implemented

- [x] Foco acompanha carregamento e etapas; controles e grupos têm nomes compreensíveis.
- [x] Perguntas, seleção, salvamento e erros são identificados sem anúncios duplicados.
- [x] Avanço automático é informado e o retorno após envio pode ser pausado.
- [x] Fluxo por teclado inclui voltar, pular, falhar e tentar novamente; somente NPS é obrigatório.
- [x] Registrar os testes realizados e os leitores de tela ainda não validados.

**Validação:** teclado, foco, árvore de acessibilidade, mensagens de erro, nova tentativa e pausa de confirmação verificados no navegador. NVDA e VoiceOver não foram executados; a homologação com esses leitores permanece pendente.
